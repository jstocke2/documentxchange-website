One clear path

Find it. Request it. Contribute it.

Search available records first. If the record is not listed, post a free request so a contributor can help locate it.

⌕

Find

Search titles and OCR-extracted details such as names, addresses, case or docket numbers, parcel numbers, dates, document type, state, and county.

02

Request

Select the document type, location, and identifying details. DocumentXchange estimates pages and pricing automatically. Posting is free; you pay only if you choose to buy a submitted document. Requests stay open for 14 days.

03
⇧

Contribute

Verified U.S.-based contributors can upload one complete, eligible public-record document. The platform enforces U.S. contributor and payout eligibility, then checks quality, page order, completeness, duplicates, and metadata. Approved listings can earn royalties when purchased.

Built for useful records

See enough to buy confidently—not enough to replace the purchase.

Protected previews show every page with graduated blur and a clear watermark. AI-assisted checks help identify non-documents, duplicates, missing sections, mixed documents, and page-order problems before a listing is approved.

  • Every listing represents one document
  • Searchable metadata extracted from the record
  • Admin review for flagged or uncertain uploads
